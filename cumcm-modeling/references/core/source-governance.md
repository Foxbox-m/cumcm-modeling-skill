# CUMCM 语料来源三层治理与双轨隔离规则

## 1. 核心治理原则（双轨隔离）

本 Skill 强制执行“规则—经验—题目自适应”三层治理，兼顾规则层与方法/表现层隔离，禁止将非参赛资料（期刊、教材、教学论文）的排版或行文风格直接带入竞赛论文生成：

**可移植性契约**：核心建模、验证、写作和排版产出不依赖原始论文库。常规入口是题面、当前 `PROJECT_ROOT` 以及 Skill 包内的离线蒸馏先验、模型卡和工具；外部论文库仅是满足明确触发条件时的可选证据扩展，可放在任意 `CORPUS_ROOT`，不得假定相邻 `论文/` 目录存在。

- **L0 官方硬项（Rules & Compliance Layer）**：当届官网、赛区通知和题面明确要求；`R` 只在最终提交审计或用户明确询问规则时读取。L0 优先级最高，任何经验默认均不得覆盖它。
- **L1 国奖与高质量官方展示经验（Evidence/Presentation Layer）**：由多篇已核验的国奖样本与高质量官方展示样本支持的结构、版式和表达默认。L1 不是官方条款，不覆盖题面、用户要求或 `submission_profile`；有实质理由偏离时记录理由即可，不另建 manifest。普通论文仅在已有独立模型与结果的写作/表现校准阶段先用离线蒸馏先验，只有需要来源追溯、历史失败案例、方法适配/反例或精确页码核验才回退 A1R/A1/A1Q。
- **L2 题目自适应层（Problem-adaptive Layer）**：由当前题目的目标、数据、约束、适用时的可辨识性、验证和交付要求决定模型、章节和图表；不得因历史频率或 L1 习惯机械套用。
- **方法层（Methodology Layer）**：决定赛题拆解、候选模型提出、数学推导、算法实现、敏感性分析与验证路径。A1R/A1/A1Q、M1 与 M3 仅用于学习模型选择思路、取舍依据、改造方式和失败边界，不构成模型种类白名单。

## 3. 表现层跨论文证据原则

- **禁止单篇定标**：任何写作句式、版式或图表习惯，必须至少由 **2 篇独立论文**共同支持，并尽量跨年份、跨题型；“多篇支持”不只看出现次数，还必须抽象出与题解内容无关的适用/决策条件，检查差异与反例，再由当前题 L2 判断是否采用；
- **单篇特征归为观察项**：仅有单篇 A1R/A1/A1Q 采用的特殊格式，仅作为备选案例，不得固化为强制模板；A1Q-B 不能单篇参与定标；
- **全文复核不提升泛化等级**：单篇全文结构/版面复核只能提高该样本观察的可信度，不能把单样本候选提升为跨题默认；具名论文及其章节、措辞、图式、步骤、方法或数字不得出现在运行层规则、脚手架或 checker 条件中；
- **无合格证据时的中性回退**：若某一表现细节在 A1R/A1/A1Q-S/A 样本中存在分歧或缺失，采用中性通用方案，并注明证据边界。

## 4. 方法层开放性原则

- **先独立推导、再结构参考、历史按需调用**：先从当前题目的目标、变量、约束、数据结构、机理与不确定性生成候选范式并写入独立简报，再按需读数学原语与相关模型卡；表现先验仅在已有独立模型与结果的论文写作/表现校准阶段读取，历史方法仅在来源追溯、失败案例或方案比较时调用，降低被往年常见套路锚定的风险。
- **学习选择逻辑，不复制模型清单**：优秀论文和专家评析提供“为什么选、为什么不选、如何组合、怎样验证”的证据；某模型在历史论文中高频出现，不构成当前题目采用它的理由。
- **候选空间不封闭**：允许采用本地模型库未收录的经典或新方法、自建数学模型、机理—数据融合、分阶段模型和跨模型组合。必要时可查阅权威原始论文、官方文档或教材补足依据。
- **来源不能代替验证**：无论候选来自获奖论文、专家评析、研究文献还是独立推导，都必须在本题上检查假设、适用时的可辨识性、误差、稳定性、计算代价和失败边界。
- **模型库只做检索加速**：五类模型专题与方法矩阵是可扩展的线索库，不得作为允许/禁止模型的白名单或穷举目录。

## 5. 严格标签与 A1 调用层的当前覆盖

`A1`、`A1Q`、`A1R` 不得互相重命名。严格 `A1` 当前共有 21 条元数据，其中 19 份可读 PDF；年份落在 2012、2014、2015。可读 PDF 的机器判定是原始 `format=pdf`，或 `readable_derivative` 以 `.pdf` 结尾。

`A1Q` 当前为 2018 年 12 篇，是 **A1 调用层质量标签，奖级未核验**；不能改写为严格 A1。`A1R` 总体为 2021—2025 年 27 份近年官方展示优先样本，逐年为 5/5/5/5/7；本次已审计的指定子集为 15 份，奖级未逐队匹配，内容质量未逐篇完成。相关审计属于可选外部语料证据；需要时通过显式 `CORPUS_ROOT` 或 `--metadata` 定位其审计文件，不依赖 Skill 包内固定相对路径。2019、2020 当前在 A1/A1Q/A1R 层均缺位。

覆盖审计不下载或补录论文，使用：

```bash
python3 <SKILL_ROOT>/scripts/search_corpus.py --corpus-root <CORPUS_ROOT> --coverage
python3 <SKILL_ROOT>/scripts/search_corpus.py --corpus-root <CORPUS_ROOT> --coverage --json
```

该命令从当前元数据实时计算年份和数量；覆盖统计是治理证据，不是奖级判断或内容质量证明。
