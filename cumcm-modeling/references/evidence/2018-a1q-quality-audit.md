# 2018 年官方展示论文 A1Q 质量审核报告

## 标签边界

`A1Q` 表示论文来自 2018 年官方展示页面，并已完成本地全文、方法证据和版面质量审核，达到本 Skill 的 A1 调用层次。它是质量标签，不是奖级标签；在官方获奖名单完成匹配前，不得把这些论文表述为“已确认全国一等奖”。

## 审核方法

逐篇检查完整 PDF，而不是只看标题或摘要。审核覆盖：题意响应、模型与算法完整性、结果证据、验证与局限、可复现线索、写作结构、图表公式和页面可读性。

- `S`：证据链完整，可优先用于方法与表现层交叉归纳。
- `A`：整体合格，可参与跨论文归纳；缺失的验证环节必须由其他样本补足。
- `B`：保留在 A1Q 层作补充案例；不能单篇决定模型选择、写作模板或图表规范。

## 跨论文调用规则

1. 表现层默认规则至少由两篇 `A1` 或 `A1Q-S/A` 独立论文共同支持；`A1Q-B` 只能补充观察。
2. 方法层调用必须回到表中页码核对假设、输入输出、验证方式和失败边界，并在当前赛题数据上重新实现。
3. 同题三篇样本应作为互补方案比较，不重复累计为同一知识点的多份证据。
4. `A1Q` 可以表述为“2018 官方展示、质量审核通过”，不得省略“奖级未核验”的来源边界。
