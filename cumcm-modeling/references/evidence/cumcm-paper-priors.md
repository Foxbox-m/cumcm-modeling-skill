# CUMCM 论文离线蒸馏先验

本文件只保存当前本地证据矩阵支持的稳定观察与失败模式，供 `cumcm-paper-playbook.md` 在独立建模和结果核验之后校准表达。它不是官方规则、奖级配额或模型白名单；CUMCM 七章脚手架是高可用默认模板，不是跨题硬门，更不能倒推为样本因果或官网条款。

## 证据边界

- 严格 A1 矩阵的 19/19 篇单栏只是有界本地观察：样本覆盖 2012、2014、2015，不能外推为全国统一版式、投稿要求或获奖条件。
- A1R 是官方展示材料的非原始 PDF，奖级未逐队匹配；A1Q 是官方展示/质量层且奖级未必核实。两者都不能支持具体奖级或官方硬项结论。
- 当届规则、赛区通知、题面和用户交付要求优先。若需要新方法、反例或精确页码，才定向查语料并保留来源边界；不创建 `paper-cases.jsonl`、pattern DB、archetype 目录或无证据占位文件。

## 证据强度与使用方式

| 观察层 | 当前证据 | 可以支持 | 不能支持 |
|---|---|---|---|
| L0 官方硬项 | 当届官网、赛区通知、题面原文 | 合规判断与阻断项 | 论文质量或获奖预测 |
| L1-强 | 严格 A1 19 篇；单栏 19/19，问题分析或等价标题 19/19，显式任务映射 19/19 | 跨论文稳定的表达与结构默认 | 全国统一版式、奖级因果 |
| L1-中 | A1 严格集首屏摘要 15/19；4 篇旧附件有前置页 | 摘要页的常见做法及例外提醒 | “第一页必为摘要”的无条件规则 |
| L1-受限 | 指定 A1R 15 篇；单栏、摘要首屏、问题分析/等价、显式映射均 15/15 | 近年官方展示经验的受限观察 | 逐队奖级、近年国一、官方硬项 |
| L2-题目自适应 | 当前题目标的、数据、机理、约束与验证 | 本题的模型、章节、图表和深度 | 历史频率替代本题证据 |

证据强度只描述可观察范围，不是质量评分。任何 L1 默认须服从 L0，并由 L2 检查是否适合当前题；实质偏离时在正文或工作记录说明原因即可，不另建 manifest。

### 本次三篇近年展示样本的受限复核

本轮 A163 的章节数量与合并关系判断来自对本地 45 页全文的结构/版面复核；这只提高该单样本观察的准确性，不提高其跨题泛化等级。语态蒸馏仍只使用 `competition-paper-voice-distillation.md` 所列选择性页码锚点，且不得扩张为奖级、因果或题解内容证据。

- `2023_A0165.pdf` 的可见主线为：问题重述（1.1/1.2）→逐问问题分析→模型假设→“符号说明及名词定义”三列表→统一“模型建立与求解”且按 5.1—5.3 映射→模型检验→模型评估→参考文献→附件清单与代码。
- `2024_A163.pdf` 同样采用逐问摘要、1.1/1.2、逐问分析、模型假设/符号、统一“模型的建立与求解”和模型评价，但把假设与符号合并为一章，未设置独立的跨问“模型的分析与检验”一级章。
- `2025_A196.pdf` 的前五页可见逐问摘要、1.1/1.2、2.1—2.5，以及独立的假设和符号表；其第五章标题实际为“模型准备”。该材料是 A1R 展示转制，单队奖级未核验，因此只能支持逐问导航和局部结构观察，不能说它逐字采用“模型的建立与求解”，也不能把“模型准备”推导为本 Skill 的结构要求。

因此，A163、A0165 与 A196 呈现出章节合并、标题和检验组织上的结构差异；这些受限样本只能共同支持功能导航、逐问映射和必要符号解释，不能由任一单篇决定默认结构，也不支持精确七章跨题硬门。七章脚手架只作为跨样本综合后的高可用默认模板；只有用户、题面或模板明确要求精确七章时，检查器才以 `--strict-structure` 执行内部模板门，且不得标为官方要求。

### Functional Coverage Contract

普通 CUMCM 稿必须覆盖：题目理解与任务映射；必要假设和符号；模型推导与求解；正式结果及现象/机理解释；决定性验证；局限与评价；参考文献；附录完整代码和材料清单。上述功能可以合并、拆分或按问题/模型组织，不新增 Schema 字段。`--award-style-audit` 只对功能覆盖作保守定位，无法从文本层确认时进入人工检查，不以关键词命中证明质量。

## 稳定的表达观察

以下观察可作为审稿风险提示，但不应转化为数量 KPI：

1. 摘要通常压缩背景，以高密度交代研究对象、任务方法、正式量化结果和验证/边界；高密度不是缩字号或堆算法名。
2. CUMCM 论文用稳定导航降低阅卷定位成本；默认七章模板可作为起点，真正重要的是每项输出都能定位到输入、模型、求解、结果、验证和直接作答。
3. 公式常用三明治表达：前文说明依据或目的，公式承担一个动作，后文解释符号、单位、参数来源、假设和后续作用。
4. 图表是 claim-driven：先提出要回答的问题，再呈现与主张匹配的数据结构，随后读取差异或趋势并交代结论边界。孤立摆图和只写“如图所示”不构成证据。
5. 优化题优先写基线、目标、可行性、活跃约束、上下界和收敛依据；数据题优先写输入诊断、预处理影响、对照和样本外风险。
6. 机理题优先写状态、单位、边界、初值、守恒与离散依据；决策题优先写指标、权衡、敏感性和可执行输出。模型名称或历史频率不能代替这些论证。

## 默认强度与偏离条件（非 KPI）

下表把强默认、条件默认和禁止事项放在同一维护层视图中。它只描述经验强度和偏离条件，不能转化为自动候选数、页数、图表数或格式门禁；每次使用仍由当前题面和证据决定。

| 经验 | 强度 | 偏离/适用条件 |
|---|---|---|
| 摘要围绕对象、任务、方法、正式结果和验证/边界；正文承接题面任务 | 强默认 | 题面或 profile 另有要求时服从真实要求；不以固定字数执行 |
| 用最短充分直觉引出新关系，随后立即进入数学表达 | 经验默认 | 只有存在真实认知缺口时添加；不写成长背景或探索日志；不是官方硬项或 KPI |
| 按真实 Cascade/Parallel/Hybrid 关系组织多问叙事 | 经验默认 | Cascade 才写继承与增量，Parallel 保持独立，Hybrid 只写真实共享核心；不是 Schema 字段或硬门 |
| 主要结果先解释题目现象和主导机制，验证只关闭尚未关闭的风险 | 经验默认 | 机制须来自当前模型；验证强度由风险决定，不规定每问固定数量；不是官方硬项或 KPI |
| 全局局限集中表达，局部公式依据留在首次依赖处 | 经验默认 | 局部简化若改变公式成立条件必须就近解释；不重复免责，也不替代整体局限 |
| CUMCM 默认使用七章脚手架，参考文献与附录不编号 | 高可用默认模板 | 普通稿可有理由合并、拆分或按问题/模型组织；精确七章仅在明确要求时进入 strict 内部门 |
| 默认模板使用 1.1/1.2、2.1—2.N、5.1—5.N、7.1/7.2 | 模板导航默认 | 普通功能模式只要求题号/语义任务映射；无显式题号时不得臆造 N |
| 显式小问保持题号映射，每项输出可定位模型、结果、验证和直接作答 | 强默认 | 无显式编号时建立语义任务映射；纯解析任务可用推导/边界表 |
| 公式、图表和结果服务于可追溯主张，先提出问题再读取证据 | 强默认 | 若某图表不承担主张则删除；图型按数据结构改变 |
| 关键结果来自同一正式运行事实源 | 强默认 | 运行细节放结果清单，只有影响可信度时在正文解释；不建立第二事实源 |
| 按 Functional Coverage Contract 组织题目理解、模型、结果、验证和评价 | 强默认 | 使用七章模板时映射到相应章节；其他结构按语义任务区间完成同样闭环 |
| 单栏 | 强默认 | 来自 19 篇严格 A1 的有界观察，不是官方规则；MCM_NATIVE、用户模板或可读性要求冲突时服从真实要求 |
| 表题在上、图题在下、正文先文后图 | 中等/条件默认 | 优先采用以保持阅读顺序，但服从模板、版心、可读性和 MCM_NATIVE 要求；不是官方规则 |
| 默认模板中假设与符号独立成节，共享模型可置于第五章开头 | 模板默认 | 普通稿允许假设/符号合并或就近定义，只要首次依赖前可定位且含义、单位清楚 |
| 2×2 面板、综合指标、统一配色或长推导 | 条件默认 | 需共享主张、可比较尺度或明显减少重复；版心不可读即拆分 |
| 26–29 页、固定每问页数、固定图表/公式数 | 维护诊断 | 页数只在实际渲染后诊断；不作为审批或获奖门槛，不向任务简报写入人为事实 |
| 用历史频率选模型、复制固定组合、堆算法名或水字数 | 禁止 | 回到当前题结构、baseline、验证和结论边界；历史只能校准或反证 |
| 把 A1R/A1Q 展示材料写成逐队奖级或官方硬项 | 禁止 | 必须保留奖级未核验、展示材料等证据边界 |

## 四类题型的答卷节奏

| 题型 | 建议叙事顺序 | 必须回答的风险 |
|---|---|---|
| 优化/配置/调度/路径 | 任务与决策 → 基线 → 目标与可行域 → 求解 → 活跃约束/权衡 → 局部验证 → 直接方案 | 约束是否满足、增益是否归因于主模型、解是否稳定 |
| 预测/统计/机器学习 | 数据与切分 → 基线 → 特征/模型 → 训练与参数 → 样本外结果 → 误差/不确定性 → 外推边界 | 泄漏、切分影响、基线差异和未观测区间 |
| 机理/微分方程/仿真 | 状态与坐标 → 关系/守恒 → 参数与边界 → 离散/求解 → 物理方向检查 → 观测或情景验证 → 适用范围 | 单位、初边值、可辨识性、步长/网格与守恒 |
| 评价/决策/建议 | 对象与指标 → 权重/偏好依据 → 基线或替代方案 → 排序/决策 → 敏感性 → 执行接口 → 结论边界 | 权重可解释性、排序稳定性、建议能否落回约束和结果 |

纯解析题可用推导、边界表或情形表替代数据图；替代理由要写清楚，不把历史图型当作要求。

## 常见失败模式

- 为凑篇幅设置固定章节、固定每问页数或重复“模型准备”，但没有新的证据；
- 用高阶算法名替代数学模型，或不提供简单基线、约束处理、停止条件和重复运行稳定性；
- 公式只给结果不解释变量和单位，图表没有主张、来源、正文读取或不确定性边界；
- 将预测误差、优化目标、机理参数和决策指标混成一个口径，或把手工数字分别写进摘要、表格和正文；
- 只做综合验证而遗漏最可能出错的逐任务局部验证，或把“程序运行成功”当成模型正确；
- 以历史论文中某方法出现频率选模，以平均图表/公式数量达标，或为了 26 页而水字数；
- 把 A1R/A1Q 展示材料当成逐队获奖证据，把样本习惯写成官方硬项；
- 在离线先验已覆盖时批量打开语料，或将未核验发现直接写入正式引用台账。

历史材料的调用边界、来源定位和失败案例摘录见 `method-evidence.md`；本文件不重复执行流程。

## 三条受限写作观察

以下三条只是在已有独立模型和正式结果之后，按需用于写作与图件规划的 L1 受限观察；来源锚点、六张证据卡及六张修辞综合卡的失败边界见 [`recent-writing-visual-distillation.md`](recent-writing-visual-distillation.md)。它们不改变 L0/L1/L2 分层，也不构成规则、模板或模型选择依据：

1. 当空间、流程或几何关系非平凡且首次公式依赖它们时，宜先给低歧义结构图，再进入公式；若关系简单或图会增加歧义，则省略。见 `geometry-before-equation`。
2. 多问只有在状态、参数、数据或约束确实传递时，才围绕共享核心写模型增量，并为新增部分单独安排结果和局部验证；独立任务不强行连接。见 `multi-question-model-delta`。
3. 算法说明宜先解释当前题的计算困难、可行性和结构利用，再给出参数、软件或实现细节；这些二级信息不能替代模型和验证证据。见 `structure-before-solver`。
