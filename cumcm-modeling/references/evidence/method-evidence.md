# 历史方法证据台账

> **调用边界（重要）**：普通候选生成禁止读取本文件。只有在方法来源追溯、历史失败案例或历史方案比较会改变当前论证时，才按需加载目标条目；读取后仍须回到当前题面的独立推导、实际数据和验证。模型卡与数学推导原语已分别承接候选表示入口，本台账不再提供通用模型卡或通用模型库。

## 1. 来源覆盖与权限

本地方法证据覆盖以下来源层：A1（奖级已由来源确认且文件可读）、A1Q（官方展示/质量层，奖级未必核实）、A1R（近年官方展示材料，奖级未逐队匹配且常为非原始 PDF）、M1（赛题评析）和 M3（研究与算法应用）。M2 仅作竞赛流程参考，不承担方法证据。标签描述证据边界，不代表方法优劣或当前题适配性。

| 层级 | 可回答的问题 | 不能推出的结论 |
|---|---|---|
| A1 | 已确认来源中的建模取舍、约束处理和验证做法 | 当前题应复制该方法或能获奖 |
| A1Q/A1R | 展示文本/版面中可核对的结构与方法线索 | 逐队奖级、官方统一要求或完整方法细节 |
| M1 | 专家为何抽象、舍弃或纠正常见路线 | 专家意见自动适合本题 |
| M3 | 某方法的机制、适用条件和失败模式 | 研究结果可直接迁移为竞赛结论 |

具体文件、页码、来源 URL、读取状态和权限以调用时提供的外部 `CORPUS_ROOT` 元数据、manifest 及对应文件为准；本页不另造一份记录状态源。发布版不内置论文语料或其索引。

## 2. 历史题与采用背景

| 历史题/主题 | 方法背景 | 只有在何种当前缺口下调用 |
|---|---|---|
| 交巡警服务平台设置与调度 | 选址、覆盖、服务半径和整数/组合约束；评析材料可用于核对题意抽象与常见遗漏 | 当前题确有覆盖或服务配置约束，且需要反例或来源追溯 |

| 成分数据分析与鉴别 | 闭合约束下的对数比表示、分类/聚类和成分迁移诊断 | 数据确为组成比例且独立推导已发现单纯形结构 |
| 太阳影子定位与几何反演 | 视运动几何、坐标校正、非线性反演与多解诊断 | 当前观测确由空间投影或反演关系生成 |
| 碳化硅外延层厚度测量 | 干涉极值、色散修正、全谱拟合与级次判定 | 当前数据确含光谱干涉且需追溯厚度反演方法 |
| 烟幕遮蔽与无人机路径 | 视线几何、风场/扩散、时空协同与组合优化 | 当前题存在遮蔽、路径或时空资源耦合 |
| 时间序列、金融与极值预测 | 滚动回测、波动/尾部建模、混合模型和泄漏风险 | 当前题需要外推且数据生成/切分问题未被本地先验覆盖 |
| 网络、流量与通讯设计 | 关联矩阵、流守恒、容量、路径/割与连通性 | 当前对象天然是图且需要历史反例或来源页码 |

这些行只记录采用背景，不是题型到模型的自动映射。当前题的目标、变量、约束和数据若不匹配，应保留不采用及其理由。

## 3. 方法、失败与可迁移机制台账

调用单条来源时，按以下字段摘录，避免把整篇历史论文搬入工作上下文：

| 字段 | 记录内容 |
|---|---|
| 来源与定位 | 记录层级、record id、文件、页码/段落和 URL；A1R/A1Q 写明其奖级边界 |
| 历史任务 | 题目动作、对象、数据和交付物，不能只记算法名 |
| 采用背景 | 为什么当时选择该表示、目标、约束或求解器 |
| 数学方法 | 最小方程链、变量/状态、目标、约束和验证接口 |
| 失败/限制 | 数据泄漏、不可辨识、局部最优、边界遗漏、离散误差、参数敏感或外部依赖 |
| 可迁移机制 | 可被当前题重新推导的结构部件，例如守恒、坐标变换、流约束、滚动切分或对照设计 |
| 当前差异 | 当前题缺少的变量、不同尺度/数据、不同约束与不可直接迁移的结论 |
| 调用决定 | `candidate_unverified`、采用、反驳或不采用，以及需要的本题验证 |

可迁移的是机制，不是题目专有数字、结果、段落、代码、权重或固定组合。若来源只给出成功结果而无失败边界，应把该缺口记录为风险，不补写推测。

## 4. 调用流程与停止边界

1. 先完成当前题的独立结构推导；只有表示存在歧义时做 representation search，只有存在可利用结构时做 invariant search，只有存在真实模型选择或替代解释时做 counter-model test。每项任务保留有意义的最小参照（现状、朴素、松弛、解析特例或极限情形均可）和可交付 baseline，再完成 Schema 4 简报；普通候选不打开本文件。
2. 明确缺口属于来源追溯、历史失败案例或历史比较之一，并只检索最小来源单元；不按历史出现频率投票选模。
3. 摘录机制、适用条件、限制和与当前题差异，状态先保留为 `candidate_unverified`；任何进入正式结论的内容必须由当前数据、推导或实际运行重新支持。
4. 若调用没有改变表示、验证设计、失败边界或来源核验，就停止读取并回到当前题工作区。

历史台账不得成为表现层规范、候选数量门禁、pattern DB、固定模型组合或第二套结果/引用状态源。论文普通写作只遵循 `cumcm-paper-playbook.md`；先验观察只遵循 `cumcm-paper-priors.md`。
