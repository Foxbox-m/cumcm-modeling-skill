# CUMCM 物理机理与动态仿真模型专题指南

> **核心原则**：量纲一致性检验；守恒定律与状态方程；离散步长与数值稳定性分析。以下机理和仿真方法是非穷举线索，允许按题意自建、耦合或改造模型。稳定性必须结合方程类型、边界条件、离散格式和目标量判断，不存在适用于所有 PDE/时间积分器的单一 CFL 或步长规则。

只有在独立识别出当前题目的数学结构后，才把本卡片作为候选表示启动器；不能由题面关键词直接套用。

---

## 1. 通用机理建模骨架与非穷举线索

先从本题机制构建方程，不因某个领域名词直接套用下表模型：

1. 定义系统边界、时间与空间尺度、状态量、控制量、外部输入和可观测量；
2. 写出适用的质量、数量、动量、能量、电荷或概率平衡，并明确源项、汇项与相互作用；
3. 补充本构关系、转移率、几何关系或经验闭合项，区分可测参数、待估参数和不可辨识组合；
4. 给出初始、边界、接口和切换条件，再决定使用解析式、ODE、PDE、网络、个体、离散事件或混合模型；
5. 用量纲、守恒、极限、观测数据和替代分辨率检查抽象是否合适。

| 问题机制示例 | 可检索的方程或框架（非首选、非穷举） | 重点假设边界与检查 |
|---|---|---|
| 种群、传染、生态相互作用 | 分舱/种群 ODE、年龄或阶段结构、网络传播、个体仿真、随机过程 | 总量与出生死亡是否闭合；均匀混合、固定接触率、空间异质性和时变参数是否成立 |
| 热、质量传递、扩散与反应 | 集总参数、Fourier/Fick 型传输、扩散/反应 PDE、有限体积或多区域耦合 | 均质与各向同性、材料参数随温度变化、界面连续、边界换热和几何降维误差 |
| 刚体、结构、变质量与轨迹 | Newton–Euler、拉格朗日方程、变质量动力学、坐标变换、状态空间与控制 | 刚体或小变形近似、阻力和外场制度、坐标定义、执行器约束、守恒与终端条件 |
| 流体、交通流与人群 | 连续性/动量守恒、LWR 类守恒律、跟驰模型、排队网络、离散事件仿真 | 连续介质适用尺度、基本图或闭合关系、激波/拥堵边界、到达与服务过程稳定性 |
| 电路、化学反应与材料过程 | Kirchhoff 定律、反应动力学、能量/电荷平衡、反应网络、多物理场耦合 | 反应级数或本构参数依据、准稳态/局部平衡、温度耦合、参数可辨识性 |
| 空间几何、天体与光学 | 坐标/投影变换、球面几何、光线追迹、干涉与色散、参数反演 | 球面或薄层近似、大气折射与时差修正、测量误差、多解性和坐标约定 |
| 可靠性、维护与离散系统 | Markov/半 Markov、更新过程、故障树、离散事件、库存与服务系统仿真 | 独立性、平稳性、记忆性、删失数据、稀有故障与状态转移证据 |
| 混合动态与反馈控制 | 状态空间、切换/事件系统、MPC、最优控制、状态估计、数据—机理融合 | 可观测与可控性、时延、噪声、切换逻辑、约束可实施性和闭环稳定性 |

表中框架只是检索入口。实际题目可能需要库外模型、自建守恒关系、多个尺度或连续—离散耦合；历史题型不能限定候选空间。

## 2. 动态仿真与蒙特卡洛随机模拟

1. **微分方程数值解法**：可比较 `solve_ivp` 的显式/刚性求解器或其他适合方法；容差与步长由尺度、刚性和收敛实验确定，`rtol=1e-6` 仅是可测试起点；
2. **蒙特卡洛抽样次数**：由目标精度、尾部事件和计算预算决定，通过均值、方差、分位数或置信区间的收敛诊断确定是否足够，而不是机械采用固定次数；
3. **极端边界检验**：在输入参数趋近于 0 或无穷大时，检验模型极限输出是否符合常识物理规律。

## 3. 参数辨识与数值验证入口

- 含未知参数的 ODE/PDE、反演或状态空间模型，在拟合前列出观测量、参数进入方程的组合形式和可辨识性风险；按 `../workflow/validation-and-sensitivity.md` 检查灵敏度 Jacobian、近奇异性、多初值稳定性和参数区间。
- 对网格、时间步长、容差和求解器做细化/替代实验。双曲型守恒律应关注 CFL、通量格式、激波和熵条件；扩散/抛物型问题应关注扩散数、隐显式格式和边界层；反应扩散、刚性 ODE 或耦合系统还需检查反应时间尺度、非线性迭代与误差控制。上述理论条件不能替代边界条件、非线性迭代和最终目标量的实际收敛证据。
- 机理模型应区分结构误差、参数误差、观测误差和数值误差，避免用一次良好拟合同时宣称四者均已解决。

## 4. 统一 Method Cards（非穷举）

### ODE / PDE 数值离散

- **适用结构**：连续时间状态演化、空间分布、守恒/扩散/反应与边界耦合。
- **核心数学形式**：ODE \(\dot x=f(t,x,u;\theta)\)；PDE \(\partial_t q+\nabla\cdot F(q)=S(q,x,t)\)，再以有限差分、有限体积或有限元离散。
- **关键假设**：状态、边界/初值、本构关系和尺度闭合；离散格式满足与方程类型相称的稳定性/守恒要求。
- **最小基线**：解析解、低阶/粗网格、静态或无耦合简化模型。
- **参数/约束注意**：单位、网格/步长、刚性、边界层、通量、非线性迭代和参数可辨识性必须说明。
- **最低验证**：网格/步长/容差细化、守恒与极限、替代求解器或解析基准；报告目标量收敛而非只报程序完成。
- **常见失败**：只改变步长不检查边界；将一次拟合误差当作结构正确；忽略刚性、激波或数值耗散。
- **实现入口**：`scipy.integrate.solve_ivp`、`scipy.sparse`、`FEniCS`、`FiPy` 或自建离散算子。

### Monte Carlo

- **适用结构**：参数/输入随机、不确定性传播、置信区间、尾部事件或复杂可行域概率。
- **核心数学形式**：\(\hat\mu_N=N^{-1}\sum_{i=1}^N g(\xi_i)\)，用样本方差/分位数估计不确定性或风险概率。
- **关键假设**：抽样分布、依赖结构和随机种子/重复方案对应目标总体；尾部采样策略与问题相称。
- **最小基线**：确定性名义参数、解析矩估计或单一情景。
- **参数/约束注意**：由目标精度、尾部风险和预算决定样本量；记录截断、相关抽样、稀有事件加权和可行性处理。
- **最低验证**：均值/方差/分位数随样本量收敛，独立重复或置信区间，极端输入和可行率检查。
- **常见失败**：固定次数无依据；独立抽样破坏相关结构；少数最好样本被写成确定结论。
- **实现入口**：`numpy.random.Generator`、`scipy.stats`、准蒙特卡洛或题意自建抽样器。

### 离散事件 / 系统仿真

- **适用结构**：排队、库存、交通、人群、维修等由事件驱动且状态在事件时刻跳变的系统。
- **核心数学形式**：事件序列 \(e_k\) 驱动 \(s_{k+1}=T(s_k,e_k)\)，输出由累计成本、等待时间、吞吐量或服务水平估计。
- **关键假设**：到达/服务/故障过程、优先级、资源容量与事件规则可观测或有依据；系统初始/稳态边界明确。
- **最小基线**：静态容量计算、解析排队近似或不含策略的原系统。
- **参数/约束注意**：区分预热期与稳态、随机流重用、资源互斥、事件同时发生和终止条件；不要把仿真时长当精度保证。
- **最低验证**：守恒/边界与已知情景回放，独立重复的中心趋势和离散程度，策略切换/失败率报告。
- **常见失败**：事件顺序错误、遗漏资源约束、单次运行结论或将仿真相关性写成因果。
- **实现入口**：`simpy`、`salabim` 或自建事件队列/状态转移仿真。
